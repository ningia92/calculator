# Calculator

A browser-based calculator application developed with JavaScript, HTML, and CSS as part of [The Odin Project Foundations Course](https://www.theodinproject.com/paths/foundations/courses/foundations).

## Skills Acquired

- **JavaScript Logic & Operations**
  - Implemented core arithmetic functions (add, subtract, multiply, divide).
  - Created an operation controller function to manage calculations.
  - Handled operator precedence and sequential operations.
  - Applied error handling for division by zero and other edge cases.

- **DOM Manipulation**
  - Generated a functional calculator interface with digits and operators.
  - Dynamically updated the display based on user input.
  - Managed multiple event listeners for different button types.

- **Problem Solving & Logic Flow**
  - Designed the sequential operation logic to correctly handle calculation chains.
  - Created clear state management between operations.
  - Built validation to prevent invalid inputs and operations.
  - Debugged edge cases like consecutive operator clicks and decimal handling.

## Features

- **Clean and Responsive UI**\
  Features a well-organized calculator layout with proper visual feedback for user actions.

- **Operation Chaining**\
  Supports continuous calculations where the result becomes the first operand of the next operation.

- **Clear Functionality**\
  Includes a clear button to reset the calculator state and start fresh.
